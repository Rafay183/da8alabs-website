🎬VidPy

Video editing, powered by Python.

An open-source video editor you install with pip and run on your own computer. A browser studio on localhost, a Python API and a CLI, all powered by FFmpeg. Cut, grade, title, mix and export, then get your whole edit back as code.

Everything you need, nothing you don't.

In code

A real editor. A real API.

Run vidpy studio for the visual studio, or drive everything from Python. Both use the same project format, so you can switch any time.

import vidpy

p = vidpy.Project(width=1920, height=1080, fps=30)
p.add_clip("intro.mp4", start=2, end=8).fx("cinematic")
p.add_text("SUMMER 2026", size=120, animation="zoom_pop")
p.add_audio("music.mp3", loop=True, duck=True)
p.render("final.mp4", quality="high")

# or: auto jump-cut a podcast
from vidpy import smart
smart.cut_silences("podcast.mp4").render("tight.mp4")
