⚡Velo UI

Beautiful Python web apps, in minutes.

Build dashboards, forms, data tools and chat UIs two ways: drag & drop in Velo Studio, or write a few lines of Python. Any Studio app exports to clean Python in one click. Pure standard library, zero dependencies.

Features

Everything you need, nothing you don't.

🎨

Drag & drop Studio

38 components in 6 groups: inputs, tables, charts, chat, tabs, cards and more, with live preview beside the canvas.

🧮

Spreadsheet-style formulas

Inputs are variables. Write {name} or =price * qty and the app recalculates instantly, in a safe sandbox.

⚙️

Actions without code

Buttons run steps: set variables, add to lists, show messages, change pages or call a Python function.

🔁

Smart re-rendering

Only the page function re-runs. DOM morphing keeps focus, caret and scroll, so there's no flicker.

📊

Built-in charts & tables

SVG line, area, bar and donut charts with tooltips, and tables with search, sort and paging. No extra libraries.

🚀

Deploy anywhere

velo docker vendors itself; honours $PORT on Render, Railway, Fly.io, Cloud Run, Heroku or any VPS.

In code

Drag & drop or code. Your choice.

Run velo studio for the visual studio, or drive everything from Python. Both use the same project format, so you can switch any time.

import velo

app = velo.App("Hello", accent="#6366f1")

@app.page("/")
def home(ui):
    name = ui.input("Your name", placeholder="Ada")
    n = ui.slider("How excited?", 1, 10, 7)
    ui.title(f"Hello {name or 'world'}" + " 🎉" * n)

app.run()
