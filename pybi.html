In code

From spreadsheet to dashboard in minutes.

Run pybi run for the visual studio, or drive everything from Python. Both use the same project format, so you can switch any time.

import pandas as pd
import pybi

sales = pd.read_csv("sales.csv")
products = pd.read_excel("products.xlsx")
pybi.run(Sales=sales, Products=products)

-- then, in the studio:
Revenue YTD = TOTALYTD([Total Revenue], 'Calendar'[Date])
Profit Margin = DIVIDE([Profit], [Total Revenue])
